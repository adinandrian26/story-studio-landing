⬇️ Unduh Aplikasi

Unduh Installer (.zip)

  1. Ekstrak seluruh ZIP ke satu folder → jalankan start_studio.bat. Python dipasang otomatis jika diperlukan; installer resmi Python 3.12 64-bit dan FFmpeg sudah disertakan.
  2. Tunggu pemasangan paket aplikasi selesai (perlu internet). Chrome/Edge akan terbuka setelah server siap. Jika tidak terbuka, ketik http://127.0.0.1:8765 di browser.
  3. Klik Aktivasi_Lisensi.bat → salin Kode Mesin → kirim ke penjual → tempel file lisensi yang diterima.
